\### dropX Project Roadmap



Phase 1: Network Connectivity \& Security Foundations

Outcome: The app can autonomously identify its networking environment (Wi-Fi vs. Hotspot), extract its local IP address, and is protected by a continuous SCA vulnerability scanner



Phase 2: The Core Transfer Engine

Outcome: A stable background service running an embedded Ktor server capable of streaming Android system files to a web client using secure, temporary session paths



Phase 3: The Security Handshake \& UX

Outcome: A seamless user experience where the sender generates a QR code and the receiver can only bypass the "PIN-Gate" after physical screen verification



Phase 4: Validation \& Release Readiness

Outcome: A production-hardened build verified by a final security audit, accompanied by a generated SBOM for long-term vulnerability tracking
